# v1.0.7 简洁界面

## 范围

默认界面仅显示内存状态、已用/总量和按内存排序的进程列表。删除首页 CPU/GPU、历史切换、工作组切换、排序口径、建议证据和采样统计。名称、单一内存值和点击详情构成列表行。详情保留退出确认和必要的异常提示。设置优先显示登录启动，诊断按需展开。

## 非目标

不改变采样、归因、历史/审计存储、建议引擎和信号安全策略，不清除用户数据，不修改真实登录项或既有应用实例。

## 架构

复用 MonitorViewModel 和 ProcessActionController；仅替换 SwiftUI 展示层。列表使用单一滚动区域，固定内存概况和底栏。继续观察独立的登录项与操作协调器。系统进程默认隐藏，菜单可切换显示；搜索保留。详情不再展示父链、路径、线程、CPU 累计时间和双内存口径。

## 风险

部分可用、保留数据和系统采样失败必须保持可辨认。单进程显示名称可能重复，详情保留进程编号辅助区分。隐藏诊断不应隐藏操作记录失败。退出确认及强制结束二次确认不得削弱。

## 验收

- 首页无 footprint、RSS、PID、归因、置信度等术语。
- 长名称和长列表可滚动，底部退出入口可达，空列表有明确提示。
- 详情中的退出、取消、超时后强制结束仍走既有控制器。
- 全量测试及严格并发 Debug/Release 构建通过；检查实际 SwiftUI 渲染，记录桌面验证限制。

## 阶段交付

本轮为一个完整的界面精简切片：设计、实现、验证后 focused commit 并推送既有 origin/main。保留用户所有未跟踪文件；不自动替换或重启正式应用。

## 实施与验证（2026-09-07）

- 首页宽 380 pt，列表为唯一滚动区域，高 290 pt；顶部内存概况与底部退出按钮固定。默认隐藏系统/root 进程，搜索和显示系统进程入口保留。
