# U7 可见需求与采样性能记录

日期：2026-10-23  
实现源码：`b7d15b7`（U7 提交；复审修复源码 `377ac0b`）

## 已实现

- 新增 `MonitorSamplingSurface`，菜单、概览、进程、详情、清理、历史、设置、
  压力测试分别表达系统/进程刷新需求。
- `AdaptiveSamplingPolicy` 合并所有有效可见需求，取各自更快间隔：
  - 进程/详情：系统约 3 秒、进程约 3 秒；
  - 概览/菜单/清理：系统约 3 秒、进程约 15 秒；
  - 历史/设置/压力测试：系统约 20 秒、进程约 60 秒；
  - 无可见消费者：约 20/60 秒。
- 压力激活时与既有 5/10 秒节奏合并，取更快者，不因优化降低安全采样。
- 窗口页面、详情和菜单生命周期分别注册/注销；关闭一个消费者不会撤销另一个。
- 清理检查、确认前复验、手动进程操作和内存测试仍使用独立安全采样；本次没有
  用监测缓存替代退出判断。
